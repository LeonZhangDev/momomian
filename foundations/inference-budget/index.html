本课学完，你能做什么

  • 用参数数和位宽算权重存储下界
  • 亲算一次均匀量化与误差
  • 分别看权重、KV cache、首 token 延迟和生成吞吐

搬家时把衣服真空压缩，能少占箱子，但家具、包装和通道仍要留空间；衣服也可能被压皱。量化减少数字的表示精度和存储量，运行时还要装下缓存与临时工作区。箱子变小并不能单凭这一点断言搬运一定更快。

参数量乘位宽，只是权重理论下界

粗算权重字节数为 N×bits/8。十亿参数，FP16 每参数 2 字节，约 2 GB；4 bit 每参数半字节，约 0.5 GB。GB 是 10⁹ 字节，GiB 是 2³⁰ 字节，不能混写。缩放系数、零点、分组、非量化层和打包方式还会增加存储，本课不是某个模型的实际显存测量。

本例四十亿参数：16 bit 约 8 GB=7.45 GiB；4 bit 理想下界 2 GB=1.86 GiB。只算权重，并没有证明 2 GB 显卡能加载运行。

量化把连续值映射到有限格点

为手算，本课用带符号整数范围 [-7,7]、scale=0.1、zero_point=0。量化 q=clip(round(w/scale),-7,7)，还原 ŵ=q×scale。它只是均匀量化玩具，不是 NF4 或某个框架内核实现；Python round 在恰好半数时有自身规则，本例故意避开这种临界值。

w=0.26 → round(2.6)=3 → 还原 0.3 → 误差 0.04。w=0.9 超过范围 → 裁剪到 7 → 还原 0.7 → 误差 0.2。量化并非无损压缩。

运行时还要装下 KV cache 和工作区

自回归生成会保存历史位置的 Key/Value，减少重复计算。简化 KV 字节估算为 2×层数×batch×序列长度×KV头数×每头维度×每元素字节。这里的 2 对应 Key 与 Value；使用 KV 头数，不能把分组查询注意力的查询头数随意代入。缓存实现、预分配、量化与共享都会改变实际值。

32 层、batch=1、2048 个位置、8 个 KV 头、每头 128、FP16：2×32×1×2048×8×128×2=268435456 字节=0.25 GiB。序列变为 4096 时，此简化缓存变成 0.5 GiB。训练还会有梯度、优化器状态与激活，不能直接套推理预算。

比较速度，必须把条件写清楚

先固定设备、模型版本、输入长度、输出长度、batch、精度、缓存和采样设置。预热后多轮测量，分别报告 TTFT（首 token 延迟）和解码吞吐（生成 token/秒），保留中位数或分位数。GPU 任务异步，计时边界需同步或使用合适的设备事件。低位宽可能省带宽，也可能因解量化和不匹配内核变慢，必须实测。

60 个输出 token，用 2 秒完成解码，吞吐是 30 token/s；如果首 token 还等了 3 秒，用户感受就不能只看 30。下面只有预算和误差计算，没有下载模型、GPU 显存测量或模型测速。

顺着数字与代码走一遍

这段只用 Python 标准库，不下载模型、不访问网络。本站已逐课运行并核对下方结果；核对的是本例的数值结果，不代表框架训练或 GPU 性能已通过验证。

weights = [0.26, -0.14, 0.9]
scale = 0.1
quantized = [max(-7, min(7, round(value / scale))) for value in weights]
restored = [value * scale for value in quantized]
errors = [round(abs(a - b), 2) for a, b in zip(weights, restored)]
parameters = 4_000_000_000
kv_bytes = 2 * 32 * 1 * 2048 * 8 * 128 * 2
print("q=", quantized, "errors=", errors)
print(f"weights: fp16={parameters * 2 / 2**30:.2f} GiB, int4_lower_bound={parameters / 2 / 2**30:.2f} GiB")
print(f"kv_estimate={kv_bytes / 2**30:.2f} GiB")

这组输入的运行结果：

q= [3, -1, 7] errors= [0.04, 0.04, 0.2]
weights: fp16=7.45 GiB, int4_lower_bound=1.86 GiB
kv_estimate=0.25 GiB
  1. 0.26/0.1=2.6，舍入为 3；-0.14/0.1=-1.4，舍入为 -1。
  2. 0.9/0.1=9，超过 7，裁剪成 7；还原后分别约为 0.3、-0.1、0.7。
  3. 四十亿权重：16 bit 共 8×10⁹ 字节，4 bit 理想共 2×10⁹ 字节；除以 2³⁰ 换成 GiB。
  4. 简化 KV 估算为 0.25 GiB；总运行预算还要添加量化元数据、非量化参数、临时工作区和余量。
