本课学完，你能做什么

  • 按顺序读懂 zero_grad、forward、backward、step
  • 区分 train/eval 模式与是否记录梯度
  • 理解独立验证集和数据泄漏的影响

学习做菜时，训练集像平时反复练的菜谱，你可以边试边调配方。验证集像事先留出的测验，先按现有配方做完并评分，再决定下一轮怎么练。把测验答案直接拿来改本次配方，就测不出独立表现了。

batch、step、epoch 分别数什么

batch 是这一步一起计算的一批样本；step 通常指一次优化器更新；epoch 是把训练集走完一轮。此处用一个含两条样本的完整 batch，只做一次 step。真实训练可有梯度累积，因此“每读一批”也不一定立刻发生一次 optimizer.step。

100 条样本，batch_size=10，且每批更新、无丢弃时，一个 epoch 通常是 10 个 step。若累积两批才更新，一轮只有 5 次更新。

训练的五个动作

先 model.train() 设置训练模式，再 zero_grad 清理上一步梯度，forward 计算预测，loss.backward 求梯度，optimizer.step 更新参数。PyTorch 默认会把梯度累加到 .grad；不清理就可能混入之前的梯度。刻意梯度累积可以有意晚些清零，但必须说明策略。

顺序可读成：清空草稿 → 用当前参数预测 → 对照目标算损失 → 求导 → 改参数。loss.item() 只是读取一个数，不负责训练。

eval 与 no_grad 管不同事情

model.eval() 改变 Dropout、BatchNorm 等层的运行行为，不会自动关闭梯度；torch.no_grad() 关闭此作用域内的梯度记录，不会自动将模型切为 eval。常规验证会同时用 model.eval() 和 no_grad，并且不 backward、不 step。回到下一轮训练前还要 model.train()。

“设置 eval 就不可能更新参数”是错误推断。若仍算梯度并调用优化器，参数仍可能被改；要看整个执行路径。

训练下降不代表验证更好

验证样本不参与本次参数更新，用来观察泛化。标准化、词表和特征选择也要防止把验证答案泄露到训练。反复根据同一验证集调参会间接过拟合；最终评估还应保留独立测试集。本例只有三条手写数据，只能解释更新边界，不能证明模型泛化。

下面训练 (1,2)、(2,4)，验证 (3,6)。训练后 w=1.5，训练均方损失 0.625，验证损失 2.25；两个数来自不同样本，不能直接要求验证一定更低。

顺着数字与代码走一遍

这段只用 Python 标准库，不下载模型、不访问网络。本站已逐课运行并核对下方结果；核对的是本例的数值结果，不代表框架训练或 GPU 性能已通过验证。

train = [(1.0, 2.0), (2.0, 4.0)]
validation = [(3.0, 6.0)]
w, lr = 1.0, 0.1
gradient = sum(2 * (w * x - y) * x for x, y in train) / len(train)
w -= lr * gradient
train_loss = sum((w * x - y) ** 2 for x, y in train) / len(train)
w_before_validation = w
validation_loss = sum((w * x - y) ** 2 for x, y in validation) / len(validation)
assert w == w_before_validation
print(f"w={w:.2f}, train_loss={train_loss:.3f}")
print(f"validation_loss={validation_loss:.2f}, updated=False")

这组输入的运行结果：

w=1.50, train_loss=0.625
validation_loss=2.25, updated=False
  1. w=1 时两条训练误差为 -1、-2；梯度分别为 -2、-8，平均是 -5。
  2. 训练更新 w=1-0.1×(-5)=1.5。
  3. 用新参数计算训练损失：(0.5²+1²)/2=0.625。
  4. 验证 x=3 得到预测 4.5，损失 (4.5-6)²=2.25；没有更新 w。

对照 PyTorch 的写法

框架对照代码：2026 年 10 月 30 日已在独立 CPU 环境（Python 3.12.14、PyTorch 2.15.0+cpu）运行，并核对本例的数值与运行边界。自行运行仍需安装 PyTorch；网页不会自动安装依赖或下载模型。此结果不包含真实微调或 GPU 性能验证。

import torch
from torch import nn
model = nn.Linear(1, 1, bias=False)
with torch.no_grad():
    model.weight.fill_(1.0)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
x = torch.tensor([[1.0], [2.0]])
y = torch.tensor([[2.0], [4.0]])
model.train()
optimizer.zero_grad()
loss = nn.functional.mse_loss(model(x), y)
loss.backward()
optimizer.step()
model.eval()
with torch.no_grad():
    val_loss = nn.functional.mse_loss(
        model(torch.tensor([[3.0]])), torch.tensor([[6.0]]))
print(val_loss.item())  # 验证损失约为 2.25；验证阶段不更新参数
