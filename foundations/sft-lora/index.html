本课学完，你能做什么

  • 解释 SFT 如何对示范 token 算损失
  • 区分全参数训练与 LoRA 可训练范围
  • 算一个 2×2、rank=1 的低秩增量

教新人写客服回复，可以给他问题和标准示范，让他练习更可能写出示范内容，这是训练目标。改整本手册，或只附一张可调整的补充页，是修改范围。SFT 与 LoRA 就像这两种不同问题：学什么，以及允许改哪里。

SFT：给定示范，增加目标 token 的概率

SFT 是监督微调。语言模型看到提示和已经给出的前文，对下一个目标 token 预测概率；常用负对数似然 L=-log p(target)，再对计入损失的位置汇总。训练时通常用正确前文作为条件，不是必须把自己生成的所有错误继续往下喂。

若目标 token 概率从 0.25 升至 0.5，单 token 损失从 -ln(0.25)≈1.386 降至 -ln(0.5)≈0.693。概率变大，负对数损失变小。

哪些 token 计算损失，要明确

对话训练可只对 assistant 回复算损失，也可以根据配置对完整文本或 completion 算损失。被 mask 的标签不计入目标，不代表这些提示 token 不能被模型读取。模板、截断、padding 和标签对齐出错，可能使训练优化了错误位置。SFT 不保证示范内容真实或无偏，也不等于模型记住每个样本。

“用户：退款规则？助手：请提供订单号。”若只训练助手部分，用户问题仍作为输入条件，但问题 token 不直接计入这项回复损失。

LoRA：保留底座，训练低秩增量

普通 LoRA 将某层有效权重写作 W_eff=W₀+(α/r)BA。W₀ 是冻结的原权重；A 形状 (r,in)，B 形状 (out,r)，r 是低秩宽度。训练 A、B 等明确允许的参数，前向仍使用底座。偏置、modules_to_save 等配置可能额外允许别的参数训练，必须查看 requires_grad 和优化器参数列表。

为便于手算，下面设 α/r=1。2×2 底座配 r=1 时，A 有 2 个参数、B 有 2 个，共 4 个，恰好与底座 4 个相同；这个玩具不展示节省比例。1024×1024、r=8 时，增量参数是 8×1024+1024×8=16384，约为底座的 1.56%。

训练目标与训练范围是两条轴

可以用 SFT 目标做全参数训练，也可以用 SFT 目标训练 LoRA。后续偏好优化也可使用适配器。冻结底座只表示底座参数不更新，适配器仍通过前向与梯度参与学习；它不意味着不需要损失、数据或显存。下面展示的是训练后可能得到的一组 A、B，不是默认初始化，也没有在本例执行 LoRA 优化。

本例 A=[[1,2]]，B=[[0.1],[0.2]]，BA=[[0.1,0.2],[0.2,0.4]]。默认 LoRA 常将 B 初始化为零，使初始增量为零；具体以配置为准。

顺着数字与代码走一遍

这段只用 Python 标准库，不下载模型、不访问网络。本站已逐课运行并核对下方结果；核对的是本例的数值结果，不代表框架训练或 GPU 性能已通过验证。

base = [[1.0, 0.0], [0.0, 1.0]]
a = [[1.0, 2.0]]  # (rank=1, in=2)
b = [[0.1], [0.2]]  # (out=2, rank=1)
delta = [[b[i][0] * a[0][j] for j in range(2)] for i in range(2)]
effective = [[base[i][j] + delta[i][j] for j in range(2)] for i in range(2)]
x = [1.0, 1.0]
output = [sum(row[j] * x[j] for j in range(2)) for row in effective]
print("delta=", delta)
print("output=", [round(value, 2) for value in output])
print("base_unchanged=", base == [[1.0, 0.0], [0.0, 1.0]])

这组输入的运行结果：

delta= [[0.1, 0.2], [0.2, 0.4]]
output= [1.3, 1.6]
base_unchanged= True
  1. 底座 W₀ 是 2×2 单位矩阵，输入 [1,1] 原本输出 [1,1]。
  2. B 的每一项乘 A 这一行，得到 2×2 的 BA 增量。
  3. 设缩放为 1，W_eff=[[1.1,0.2],[0.2,1.4]]；乘输入得到 [1.3,1.6]。
  4. 底座列表没有被修改。这里只验证低秩前向代数，没有实现反向传播或真实微调。
