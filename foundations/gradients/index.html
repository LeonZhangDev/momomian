目录记笔记

本课学完，你能做什么

  • 用误差平方算一次损失
  • 解释导数的方向及学习率的作用
  • 算完前向、求梯度、更新参数与重新检查

调节淋浴水温时，你先比较当前温度和目标温度，再决定旋钮往哪边动、动多少。损失衡量偏差，梯度提示局部变化方向，学习率决定这次调节的步幅。步子太大，可能从偏冷一下调成过热。

模型先做一个最小预测

这里的模型只有一个可学习参数 w，输入 x，预测 ŷ=w×x。训练样本 x=2，目标 y=4；初始 w=1，预测就是 2。参数是可被优化的数，输入数据不是本例要更新的参数。

如果 w=2，输入 2 才会预测 4。但训练过程先从 w=1 开始，按规则一步一步靠近。

损失把偏差写成一个数

本课使用单样本平方损失 L=(ŷ-y)²。初始误差 2-4=-2，平方损失为 4。平方后不分正负，但大误差惩罚更大。多样本时可取平均；不同损失的定义会改变公式系数，不能随意把“平方和”与“均方”混用。

两个样本误差为 -2、1 时，平方和是 5，均方误差是 (4+1)/2=2.5。

导数是当前位置的变化率

导数 dL/dw 说明 w 增加一小点时，损失局部会怎样变化。由于 L=(wx-y)²，链式法则得到 dL/dw=2(wx-y)×x。代入得到 2×(-2)×2=-8。负号表示在当前位置稍微增大 w 会降低损失；它不是“负损失”。

可用小步 h 检查：(L(w+h)-L(w-h))/(2h) 约等于导数。这个数值差分是核对手段，不是本课框架自动求导的实测。

沿负梯度走，再重新算一次

梯度下降更新 w_new=w-lr×grad。取学习率 lr=0.1，w_new=1-0.1×(-8)=1.8；新预测 3.6，新损失 (3.6-4)²=0.16。backward 负责求梯度，优化器 step 才执行更新，不能将两步混为一谈。

同一位置若 lr=1，w_new=9，新损失 (18-4)²=196。一次更新并不保证损失下降，学习率过大会越过目标。

顺着数字与代码走一遍

这段只用 Python 标准库，不下载模型、不访问网络。本站已逐课运行并核对下方结果；核对的是本例的数值结果，不代表框架训练或 GPU 性能已通过验证。

x, target, w, lr = 2.0, 4.0, 1.0, 0.1
prediction = w * x
loss = (prediction - target) ** 2
gradient = 2 * (prediction - target) * x
w_new = w - lr * gradient
new_loss = (w_new * x - target) ** 2
print(f"loss={loss:.2f}, gradient={gradient:.2f}")
print(f"w={w_new:.2f}, new_loss={new_loss:.2f}")

这组输入的运行结果：

loss=4.00, gradient=-8.00
w=1.80, new_loss=0.16
  1. 前向：w=1，x=2，所以预测为 2。
  2. 损失：(2-4)²=4。
  3. 求导：2×(2-4)×2=-8。
  4. 更新：1-0.1×(-8)=1.8；重新前向后，损失变成 0.16。

对照 PyTorch 的写法

框架对照代码：2026 年 10 月 30 日已在独立 CPU 环境（Python 3.12.14、PyTorch 2.15.0+cpu）运行，并核对本例的数值与运行边界。自行运行仍需安装 PyTorch；网页不会自动安装依赖或下载模型。此结果不包含真实微调或 GPU 性能验证。

import torch
w = torch.tensor(1.0, requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)
optimizer.zero_grad()
loss = (w * 2.0 - 4.0) ** 2
loss.backward()  # 计算 w.grad，还没有更新 w
optimizer.step()  # 才更新 w
print(w.item())  # 浮点数约为 1.8
