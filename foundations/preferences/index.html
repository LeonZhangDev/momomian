本课学完，你能做什么

  • 读懂同一提示下 chosen/rejected 的比较
  • 用参考模型计算一个 DPO 损失
  • 区分偏好分数、奖励与真实正确性

让评委对同一道菜的两个版本选更喜欢的一个，比只给一道标准菜谱多了一种信号。但评委可能只喜欢摆盘、口味可能偏某一群人；反复追求评委分数，不能自动保证营养、卫生和所有顾客满意。

先准备可比较的一对回答

偏好数据通常是同一提示 x、较偏好的回答 y⁺ 和较不偏好的回答 y⁻。chosen 只是标注更偏好，不自动意味着全部事实正确；标注还可能偏向更长、更迎合或某种风格。提示、任务范围与评分依据必须一致，冲突标签要检查。

同一问题“给出退款流程”，一条回答清楚且符合当前规则，另一条使用过期规则。偏好标注应有依据；不能让两个不同问题的回答直接冒充这一对。

DPO 同时看策略与参考模型

策略 πθ 是要训练的模型，参考 πref 是比较基线。记 m=[ln πθ(y⁺|x)-ln πref(y⁺|x)]-[ln πθ(y⁻|x)-ln πref(y⁻|x)]。标准 sigmoid DPO 的单对损失是 L=-ln σ(βm)，σ(z)=1/(1+exp(-z))，β>0。本课只讲这一种损失，不能套到所有 DPO 变体。

设策略对两条完整回答的概率为 0.6、0.2，参考都为 0.25，β=1。m=ln(0.6/0.25)-ln(0.2/0.25)=ln3；σ(m)=0.75，损失约 0.287682。完整序列概率实际通常很小，实现会累加目标 token 的 log 概率并正确处理 mask。

优化目标不是“只让 chosen 概率上升”

DPO 比较相对参考的偏好差距；chosen 和 rejected 的概率以及参考基线共同影响目标。两者概率都可能变化，单看 chosen 一个数不足以判断目标是否改善。标准离线 DPO 可直接用偏好对训练，不要求先单独训练奖励模型，也没有在本课执行在线采样或真实训练。

若策略与参考对同一对回答的相对比值相同，则 m=0、σ(0)=0.5、损失 ln2≈0.693。这不是“回答正确率等于 50%”。

RL 奖励要定义，也要约束

强化学习常让策略采样回答，用奖励衡量结果，再更新策略以提高期望奖励。一种常见示意目标是 E[reward]-λ KL(πθ||πref)：既争取奖励，也限制过度偏离参考；具体算法还有裁剪、优势估计等细节。KL 是两种输出分布差异的度量，不是事实检查器。

若只奖励字数，模型可能变长却不更有用；若只奖励测试通过率，模型可能投机于测试。要保留独立事实核查、任务成功率、风险和分组评估，不能把奖励上涨叫作安全或正确性的证明。

顺着数字与代码走一遍

这段只用 Python 标准库，不下载模型、不访问网络。本站已逐课运行并核对下方结果；核对的是本例的数值结果，不代表框架训练或 GPU 性能已通过验证。

import math

policy_chosen, policy_rejected = 0.6, 0.2
ref_chosen, ref_rejected, beta = 0.25, 0.25, 1.0
margin = (math.log(policy_chosen / ref_chosen)
          - math.log(policy_rejected / ref_rejected))
logit = beta * margin
preference_probability = 1 / (1 + math.exp(-logit))
loss = -math.log(preference_probability)
print(f"margin={margin:.6f}")
print(f"sigmoid={preference_probability:.2f}, loss={loss:.6f}")

这组输入的运行结果：

margin=1.098612
sigmoid=0.75, loss=0.287682
  1. 策略相对参考的两个比值：0.6/0.25=2.4，0.2/0.25=0.8。
  2. 对数差等于 ln(2.4/0.8)=ln3≈1.098612。
  3. β=1，所以 sigmoid(ln3)=1/(1+1/3)=0.75。
  4. 损失 -ln0.75≈0.287682。只是给定概率的数学例子，没有模型、奖励器或训练更新。
