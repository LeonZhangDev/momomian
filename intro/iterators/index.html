课程 / 编程与接口 / 第 9 节

迭代与取消：看懂分块到达的结果

约 13 分钟 · 选学 · 无需模型账号

函数列表与字典判断与循环异常JSON 与 HTTP一次接口调用对象与 self运行环境
选学：读懂迭代、异步与中途停止迭代与取消：看懂分块到达的结果

本课学完，你能做什么

  • 跟踪 yield 逐项产生的内容
  • 区分暂停迭代、取消与正常结束
  • 知道 async 等待并不自动创建并行任务

接收语音消息时，你会陆续收到片段。收到了前两个片段，不表示整段已经结束；主动关闭接收时，还要收好临时内容并关闭资源。

生成器一次产生一个值

函数含 yield 时，调用会创建生成器。for 或 next 推动它执行到下一次 yield；暂停时局部状态仍保留。生成器耗尽是正常结束，提前停止则需要明确处理未完成状态。

yield "你" 后会暂停，下次继续才产生“好”；不能把“暂时没拿到后续”当作完整答案。

停止消费与清理资源要分清

本课在取得两个片段后主动关闭生成器，finally 负责展示清理动作。真实流还应关闭响应、停止生产任务并记录取消状态。已显示的部分内容可以保留为草稿，但不能冒充完成回执。

break 只跳出循环；本例显式 close，才能立即执行该生成器的 finally。

async 是协作等待，不是自动加速

async def 定义协程，await 等待可等待对象。依次 await A 再 await B，仍可按顺序执行；显式调度多个任务才可能重叠等待。取消信号需要传递和清理，不能吞掉后继续执行写操作。

先掌握本课同步片段示例，再按需学习 LangGraph 的流式输出和并发；零基础主线无需先写并发框架。

顺着代码走一遍

def chunks():
    try:
        for text in ["你", "好", "！"]:
            yield text
    finally:
        print("stream_closed")

stream = chunks()
parts = []
for text in stream:
    parts.append(text)
    if len(parts) == 2:
        break
stream.close()
print("".join(parts))
print("cancelled")

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

stream_closed
你好
cancelled
  1. 创建生成器时尚未一次性拼成全部文本。
  2. 两次迭代分别取得你和好。
  3. 达到本课取消条件后 break，不消费感叹号；显式 close 触发清理。
  4. 保留部分文本你好，状态为 cancelled，不能标为正常完成。
