列表与字典：组织消息和工具参数

约 9 分钟 · 无需模型账号

函数列表与字典判断与循环异常JSON 与 HTTP一次接口调用对象与 self运行环境
选学：读懂迭代、异步与中途停止迭代与取消：看懂分块到达的结果

本课学完，你能做什么

  • 用列表保存有顺序的一组值
  • 用字典按字段名读取内容
  • 读懂消息列表中的嵌套结构

列表像按顺序排好的文件夹，字典像一张带栏目名的登记表。你先取第几个文件夹，再按“姓名”“内容”这样的字段找到需要的值。

列表保留顺序，从 0 开始计数

列表使用方括号。messages[0] 是第一项，messages[1] 是第二项。append 会把一项加入末尾，不能把列表下标与自然语言里的“第几项”混用。

字典用字段名描述一件事

字典使用花括号，把字段名映射到值。message["role"] 读取角色，message["content"] 读取内容。字段名与大小写都要按约定一致。

组合起来就能表达对话

一段对话可以是一个列表；其中每一条消息是一个字典。先用下标选消息，再用字段名选内容。

messages[1]["content"] 表示第二条消息的 content 字段。

顺着代码走一遍

messages = [
    {"role": "system", "content": "回答要简洁"},
    {"role": "user", "content": "你好"}
]
messages.append({"role": "assistant", "content": "你好！"})
print(messages[1]["content"])
print(len(messages))

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

你好

  1. 建立两条消息，原顺序是 system、user。
  2. append 在末尾加入 assistant 消息。
  3. 下标 1 仍指向第二条 user 消息，content 是“你好”。
  4. 列表共有 3 项，len(messages) 为 3。
