对象与 self：状态放在哪里

约 12 分钟 · 无需模型账号

函数列表与字典判断与循环异常JSON 与 HTTP一次接口调用对象与 self运行环境
选学：读懂迭代、异步与中途停止迭代与取消：看懂分块到达的结果

本课学完，你能做什么

  • 认出类、对象、属性和方法
  • 解释 self 指向哪一个对象
  • 区分实例状态与跨对象共享状态

同一种登记本模板可以印出两本登记本。模板是类，两本实物是对象，每本自己的内容是实例状态。给甲本写一行，不应让乙本也凭空多一行。

类是定义，对象是一次具体实例

class 描述一种对象有哪些状态和方法。Memory() 创建一个实例；第二次 Memory() 创建另一个实例。相同类名不表示共享同一份内容。

a = Memory() 与 b = Memory() 建立两本独立的登记本。

self 指向本次方法调用的对象

调用 a.add("偏好茶") 时，方法中的 self 是 a。self.items 读取的是 a 的属性。self 不是所有对象公用的一份隐藏数据库。

a.add("茶") 可理解为用 a 作为 self，执行 Memory.add 的规则。

把可变实例状态放在初始化方法中

在 __init__ 中写 self.items = []，会为每次新建实例建立列表。若把可变列表直接写在类体里，它可能被多个实例共享；是否共享必须是有意设计。内存状态随进程退出通常会丢失。

分开实例只能说明本进程的对象隔离，不能替代用户授权、持久化和数据库隔离。

顺着代码走一遍

class Memory:
    def __init__(self):
        self.items = []

    def add(self, text):
        self.items.append(text)
        return len(self.items)

a = Memory()
b = Memory()
print(a.add("偏好茶"))
print(a.items)
print(b.items)

  4. 返回 a 的条目数 1；b 没有被修改，仍为空。
