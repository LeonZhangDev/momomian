判断与循环：决定执行哪一步

约 12 分钟 · 无需模型账号

函数列表与字典判断与循环异常JSON 与 HTTP一次接口调用对象与 self运行环境
选学：读懂迭代、异步与中途停止迭代与取消：看懂分块到达的结果

本课学完，你能做什么

  • 按条件判断代码走哪个分支
  • 跟踪一次 for 循环中的变量变化
  • 用预算和 break 解释循环为何停止

处理一叠预约单时，你会跳过空白单，只处理仍有预算的有效单。条件像分拣规则，循环像逐张查看，break 像到达处理上限后停下。

if 只执行满足条件的分支

if 后面的表达式需要判断真假。空字符串、空列表、0、None 都是假值；非空字符串 "0" 是真值。真值表示条件能否成立，不表示业务已经成功。

if result: 会把合法数字 0 当成假值；判断字段是否存在时，应明确检查键或是否为 None。

for 按顺序取项，continue 跳过当前项

for 每次取列表中的下一项。continue 跳过本轮剩余语句，随后仍可能处理下一项。不要把“跳过一项”理解为“结束全部循环”。

空姓名被跳过；后面非空的姓名仍会进入处理。

while 在条件成立时继续，必须推动条件变化

while 会反复检查条件。若预算始终不减少、状态始终不改变，循环可能无法停止。break 可以立即结束当前最内层循环；它不会自动结束整个程序。

本课每处理一个有效名字就减少一次预算。预算降到 0 后 break，不处理后续名字。

顺着代码走一遍

names = ["", "小林", "小周", "小吴"]
remaining = 2
accepted = []
for name in names:
    if not name:
        continue
    if remaining == 0:
        break
    accepted.append(name)
    remaining -= 1
print(accepted)
print(remaining)
print(bool(0), bool("0"))

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

['小林', '小周']
0
False True
  1. 空字符串为假，continue 跳过这一张，不减少有效处理预算。
  2. 小林入列，remaining 从 2 变 1。
  3. 小周入列，remaining 从 1 变 0。
  4. 下一轮读到小吴时，预算为 0，break 结束循环。
