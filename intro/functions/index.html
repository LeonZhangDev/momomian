函数：把输入变成返回值

约 8 分钟 · 无需模型账号

函数列表与字典判断与循环异常JSON 与 HTTP一次接口调用对象与 self运行环境
选学：读懂迭代、异步与中途停止迭代与取消：看懂分块到达的结果

本课学完，你能做什么

  • 认出参数、函数体和返回值
  • 顺着代码算出一次调用的结果
  • 区分 return 与 print

把函数想成一台按规则工作的饮料机：投入的是参数，机器按步骤处理，交到你手里的成品是返回值。写好机器的说明，还不等于已经启动机器。

先定义，再调用

def 写出函数的名字、参数和处理步骤。缩进的代码属于函数体；只有调用函数时，函数体才会执行。

def add_one(value): 定义处理规则；add_one(5) 才是一次实际调用。

参数接住输入，return 交回结果

调用时，实参传给函数的参数。return 把结果交回调用处，并结束这次函数执行。调用者可以保存结果，再传给下一步。

result = add_one(5) 会把返回的 6 存在 result 中。

显示结果与返回结果分开

print 把内容显示在输出区，return 把值交给调用者。一个只调用 print、没有 return 的普通 Python 函数，默认返回 None。

后面还要计算时，应取得返回值；看见屏幕上出现数字不代表变量已经收到了它。

顺着代码走一遍

def add_one(value):
    return value + 1

first = add_one(5)
second = add_one(first)
print(first, second)

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

6 7
  1. 第一次调用把 5 交给 value。
  2. 计算 5 + 1，返回 6，保存到 first。
  3. 第二次调用使用 first 的值 6，返回 7。
  4. print 显示 first 与 second：6 7。
