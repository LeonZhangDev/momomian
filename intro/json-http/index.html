本课学完，你能做什么

  • 区分 Python 字典与 JSON 文本
  • 识别请求方法、地址、数据与返回状态
  • 判断格式错误、业务拒绝和超时的区别

一次接口请求像寄一份格式约定好的申请：地址说明送到哪里，方法说明想做什么，正文填写字段。收件成功、申请被批准和最终事情办成，是可以分开核对的步骤。

JSON 是交换数据的文本格式

Python 字典是程序内的数据结构；JSON 是一种文本格式。JSON 字符串与属性名使用双引号，布尔值写 true/false，空值写 null。应使用标准序列化器转换，避免手工拼接用户内容。

请求有方法、地址和数据

GET 通常用来读取，POST 通常用来提交处理；实际语义仍取决于接口约定。请求头可说明正文是 application/json。密钥由受控后端读取，不放进公开网页代码。

收到返回后逐层核对

HTTP 状态是线索，正文还可能有具体业务错误。200 不自动证明用户目标已完成；400 常需要修正输入；429 常需要限速处理。超时没有明确响应，需要另外核对执行结果。

顺着代码走一遍

import json

payload = {"role": "user", "content": "你好", "stream": False}
body = json.dumps(payload, ensure_ascii=False)
restored = json.loads(body)
print(restored["content"])
print(restored["stream"])

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

你好
False
  1. payload 是 Python 字典，其中 False 是 Python 布尔值。
  2. json.dumps 生成 JSON 文本，布尔值会写成 false。
  3. json.loads 把 JSON 文本解析回 Python 对象。
  4. 读出 content 与 stream，分别得到“你好”和 False；这里没有发送网络请求。
