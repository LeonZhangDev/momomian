本课学完，你能做什么

  • 顺着 try 与 except 判断执行路径
  • 只捕获能够处理的错误
  • 分清失败、结果未知和成功

收银员发现价格标签不是数字，应指出是哪张标签有问题。把错误金额写成 0 并宣布结账成功，会把问题藏进后续账单。异常处理也是如此：处理已知问题，同时保留错误的真实含义。

try 放可能失败的操作

代码遇到异常时，会停止当前正常路径。匹配的 except 接住异常后，程序才执行相应的处理分支。try 不是“保证一定成功”。

捕获具体错误，给出可恢复的返回

int("12") 可以解析为整数；int("周五") 会引发 ValueError。可以专门捕获 ValueError，返回明确的失败状态，让调用者补输入。

不要把结果未知当成没有执行

本课只演示本机输入转换。真实工具请求超时可能发生在执行前，也可能发生在执行之后。处理写操作时还要核对回执和幂等规则，不能把 except 当成无限重试许可。

顺着代码走一遍

def parse_people(text):
    try:
        value = int(text)
    except ValueError:
        return {"ok": False, "error": "人数需要是整数"}
    if value <= 0:
        return {"ok": False, "error": "人数需要大于零"}
    return {"ok": True, "value": value}

print(parse_people("2"))
print(parse_people("两位"))

预期内容如下。字典的显示可能使用单引号；判断时看字段和值。

{'ok': True, 'value': 2}
{'ok': False, 'error': '人数需要是整数'}
  1. 输入“2”能被 int 转成 2，不进入 except。
  2. 2 大于零，返回 ok=True。
  3. 输入“两位”不能转成整数，进入 ValueError 分支。
  4. 返回具体错误；不继续把失败输入当作人数使用。
