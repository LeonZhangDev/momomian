先用可检查的小数据替代大型下载

这是人工情感分类玩具，不是 IMDB 数据或 BERT 微调。训练集用两个数值特征 x=[1,-1]、标签 y=[1,0]；验证集另用 x=[2,-2]、标签 y=[1,1]。固定特征相当于已经完成分词和特征准备，不能把它当成真实 tokenizer。训练、验证与最终测试集应按样本和来源分开。

一个参数也能看清更新机制

模型正类分数 z=w×x，概率 p=sigmoid(z)，二分类交叉熵为 -y log p-(1-y)log(1-p)。w=0 时两个概率均为 0.5，平均损失约 0.693147；平均梯度是 mean((p-y)×x)=-0.5。学习率 0.2，所以 w 从 0 更新到 0.1。

验证不更新，保存要写清契约

验证时用更新后的 w 预测，阈值为 p≥0.5。两条验证预测为 [1,0]，与标签 [1,1] 比较得到一个 TP、一个 FN。验证结果可用于选择配置，最终测试应留到最后。保存至少要包含参数、特征规则、阈值与版本；本例只序列化到字符串，不写文件。

以下是本站固定教学样例，用来观察规则，不是线上服务的测量结果。

固定玩具训练集 x=[1,-1]、y=[1,0]，w=0，学习率 0.2。验证集 x=[2,-2]、y=[1,1]，正类概率阈值 0.5。

步骤当前内容或状态为什么这样变化
构造批次B=2；特征形状 [2,1]；标签 [2]本例特征已人工给定，不下载数据集或预训练模型。
前向与损失z=[0,0]；p=[0.5,0.5]；mean loss≈0.693147两条样本都贡献 -log(0.5)。
更新参数gradient=(-0.5-0.5)/2=-0.5；w=0-0.2×(-0.5)=0.1每个样本的梯度为 (p-y)×x，更新前先在批次内求平均。
冻结验证验证 z=[0.2,-0.2]；预测 [1,0]；标签 [1,1]只读 w，不在验证时做反向或参数更新。
评估与序列化accuracy=1/2；precision=1；recall=1/2；F1=2/3TP=1、FP=0、FN=1。保存内容包括 w=0.1 和 threshold=0.5。

最后得到：一次训练步后 w=0.1。验证准确率 0.5、正类精确率 1、召回率 0.5、F1 约 0.666667。小样例用于核对流程，不反映真实情感分类效果。

查看完整 Python 推导与预期输出

标准库教学程序。固定输入的输出会随课程构建核对；不访问模型或外部服务。

import json
import math
xs, ys = [1.0, -1.0], [1, 0]
w = 0.0
probs = [1/(1+math.exp(-w*x)) for x in xs]
loss = sum(-y*math.log(p)-(1-y)*math.log(1-p) for y,p in zip(ys,probs))/2
grad = sum((p-y)*x for x,y,p in zip(xs,ys,probs))/2
w -= 0.2*grad
pred = [int(1/(1+math.exp(-w*x)) >= 0.5) for x in [2.0,-2.0]]
print(round(loss,6), round(grad,6), round(w,6))
print(pred)
labels = [1, 1]
tp = sum(p == 1 and y == 1 for p,y in zip(pred,labels))
fp = sum(p == 1 and y == 0 for p,y in zip(pred,labels))
fn = sum(p == 0 and y == 1 for p,y in zip(pred,labels))
accuracy = sum(p == y for p,y in zip(pred,labels))/len(labels)
precision = tp/(tp+fp)
recall = tp/(tp+fn)
f1 = 2*tp/(2*tp+fp+fn)
print(accuracy, precision, recall, round(f1,6))
print(json.dumps({"w": w, "threshold": 0.5}, sort_keys=True))

如果这一步出错呢？

触发条件：把验证样本也用于梯度更新，或把“预测为正”数量用作所有指标分母。

验证参与更新后就不再是独立观察；本例若只报告 precision=1，会掩盖漏掉一半正类的事实。

恢复方法：为训练和验证分别标注是否允许更新，保存划分标识；先数 TP/FP/FN，再分别按公式计算指标。

import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=2, torch_dtype=torch.float16, device_map="auto"
)

# 手动推理完整流程
text = "Transformers is an amazing library!"

# 1. 编码
inputs = tokenizer(text, return_tensors="pt", truncation=True, max_length=512)
inputs = {k: v.to(model.device) for k, v in inputs.items()}

# 2. 前向传播
with torch.no_grad():
    outputs = model(**inputs)

# 3. 解析输出
logits = outputs.logits                       # shape: [1, 2]
probs  = torch.softmax(logits, dim=-1)
pred   = torch.argmax(probs, dim=-1).item()

id2label = model.config.id2label              # {0: 'LABEL_0', 1: 'LABEL_1'}
print(f"预测类别: {id2label[pred]}, 置信度: {probs[0][pred]:.4f}")
