快速入门 (Quickstart)

本快速入门将引导您在几分钟内从简单的设置到构建一个功能完整的 AI 智能体（agent）。

要求 (Requirements)

要运行这些示例，您需要：

  • 安装 (Install) LangChain 包
  • 设置 Claude (Anthropic) 账户并获取 API 密钥
  • 在您的终端中设置ANTHROPIC_API_KEY环境变量

虽然这些示例使用 Claude，但您也可以通过更改代码中的模型名称并设置相应的 API 密钥来使用任何支持的模型。

构建基础智能体 (Build a basic agent)

首先创建一个可以回答问题并调用工具的简单智能体。该智能体将使用 Claude Sonnet 4.5 作为其语言模型，一个基础的天气函数作为工具，以及一个简单的提示词来指导其行为。

补充说明：源文函数体缺缩进，天气工具本身只返回固定晴天文本。不同代码段还需按顺序放在同一示例环境；展示输出不能作为已连接真实天气服务的记录。

from langchain.agents import create_agent

def get_weather(city: str) -> str:
"""获取指定城市的天气。"""
return f"It's always sunny in {city}!"

agent = create_agent(
model="claude-sonnet-4-5-20250929",
tools=[get_weather],
system_prompt="You are a helpful assistant",
)

# 运行智能体
agent.invoke(
{"messages": [{"role": "user", "content": "what is the weather in sf"}]}
)

要了解如何使用 LangSmith 追踪您的智能体，请参阅 LangSmith 文档。

构建真实世界的智能体 (Build a real-world agent)

接下来，构建一个实用的天气预报智能体，演示关键的生产级概念：

  1. 详细的系统提示词 (Detailed system prompts)以获得更好的智能体行为
  1. 创建工具 (Create tools)以集成外部数据
  1. 模型配置 (Model configuration)以获得一致的响应
  1. 结构化输出 (Structured output)以获得可预测的结果
  1. 对话记忆 (Conversational memory)以实现类似聊天的交互
  1. 创建并运行智能体 (Create and run the agent)构建一个功能完整的智能体

让我们逐步完成每个步骤：

定义系统提示词 (Define the system prompt)

系统提示词定义了智能体的角色和行为。请保持其具体且具可操作性：

wrap

SYSTEM_PROMPT = """You are an expert weather forecaster, who speaks in puns.

You have access to two tools:

- get_weather_for_location: use this to get the weather for a specific location
- get_user_location: use this to get the user's location

If a user asks you for the weather, make sure you know the location. If you can tell from the question that they mean wherever they are, use the get_user_location tool to find their location."""

创建工具 (Create tools)

工具 (Tools) 允许模型通过调用您定义的函数与外部系统交互。 工具可以依赖运行时上下文 (runtime context)，也可以与智能体记忆 (agent memory)交互。

请注意下方get_user_location工具如何使用运行时上下文：

补充说明：这是按示例用户 ID 返回固定地点的模拟规则，并未读取真实位置。实际用户身份须由应用验证，未知用户不应被默认为某个真实地点。

from dataclasses import dataclass
from langchain.tools import tool, ToolRuntime

@tool
def get_weather_for_location(city: str) -> str:
"""获取指定城市的天气。"""
return f"It's always sunny in {city}!"

@dataclass
class Context:
"""自定义运行时上下文模式。"""
user_id: str

@tool
def get_user_location(runtime: ToolRuntime[Context]) -> str:
"""根据用户 ID 检索用户信息。"""
user_id = runtime.context.user_id
return "Florida" if user_id == "1" else "SF"

工具应该有良好的文档记录：它们的名称、描述和参数名称会成为模型提示词的一部分。 LangChain 的 @[@tool装饰器][@tool] 添加了元数据，并通过ToolRuntime参数启用了运行时注入。

配置模型 (Configure your model)

根据您的用例，使用正确的参数设置您的语言模型 (language model)：

from langchain.chat_models import init_chat_model

model = init_chat_model(
"claude-sonnet-4-5-20250929",
temperature=0.5,
timeout=10,
max_tokens=1000
)

根据所选模型和提供商的不同，初始化参数可能会有所不同；请参阅其参考页面以获取详细信息。

添加记忆 (Add memory)

为您的智能体添加记忆 (memory)，以在多次交互之间保持状态。这允许智能体记住之前的对话和上下文。

补充说明：InMemorySaver 只在当前进程内保存状态，重启后不保证保留。thread_id 区分会话，不是鉴权；应用需校验用户对相应会话的访问权限。

from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()

在生产环境中，请使用将数据保存到数据库的持久化检查点加载器。详见添加和管理记忆。

创建并运行智能体 (Create and run the agent)

现在，用所有的组件组装您的智能体并运行它！

补充说明：结构化输出约束字段形状，不证明天气事实正确。失败反馈、超时、工具调用预算和缺少位置时的恢复还需单独设计。

from langchain.agents.structured_output import ToolStrategy

agent = create_agent(
model=model,
system_prompt=SYSTEM_PROMPT,
tools=[get_user_location, get_weather_for_location],
context_schema=Context,
response_format=ToolStrategy(ResponseFormat),
checkpointer=checkpointer
)

# `thread_id` 是给定对话的唯一标识符。
config = {"configurable": {"thread_id": "1"}}

response = agent.invoke(
{"messages": [{"role": "user", "content": "what is the weather outside?"}]},
config=config,
context=Context(user_id="1")
)

print(response['structured_response'])
# ResponseFormat(
#     punny_response="Florida is still having a 'sun-derful' day! ...",
#     weather_conditions="It's always sunny in Florida!"
# )

# 请注意，我们可以使用相同的 `thread_id` 继续对话。
response = agent.invoke(
{"messages": [{"role": "user", "content": "thank you!"}]},
config=config,
context=Context(user_id="1")
)

print(response['structured_response'])
# ResponseFormat(
#     punny_response="You're 'thund-erfully' welcome! ...",
#     weather_conditions=None
# )

    Agent
    围绕目标读取状态、选择动作、观察结果并判断是否继续的程序。行动权限与停止条件需要明确设计。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Prompt
    向模型提供任务、上下文、约束和输出要求的输入内容；提示本身不能代替程序权限校验。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    记忆
    为后续使用保留信息的机制。近期会话、跨会话偏好与操作审计的范围和用途应分开。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Token
    分词器处理文本得到的单位。它不固定等于一个汉字、一个单词或一个字符。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    超时
    在设定时间内没有得到完成结果；它不单独证明远端操作没有执行。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    检查点
    在流程执行中保存的状态快照，用于继续或恢复；它本身不保证外部写入恰好发生一次。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    线程标识
    用于区分一组持久会话或工作流状态的标识。使用前需明确用户与资源的隔离范围。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LangChain
    模型、消息、工具等应用组件的框架生态。具体接口以课程标注版本和官方文档为准。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LangGraph
