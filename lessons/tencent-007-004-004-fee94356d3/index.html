示例 (Example)

下面我们演示一个简单的应用程序，它撰写一篇论文并中断 (interrupts) 以请求人工审核。

from langgraph.checkpoint.memory import InMemorySaver
from langgraph.func import entrypoint, task
from langgraph.types import interrupt

@task
def write_essay(topic: str) -> str:
"""撰写关于给定主题的论文。"""
time.sleep(1) # 长时间运行任务的占位符。
return f"An essay about topic: {topic}"

@entrypoint(checkpointer=InMemorySaver())
def workflow(topic: str) -> dict:
"""撰写论文并请求审核的简单工作流。"""
essay = write_essay("cat").result()
is_approved = interrupt({
# 提供给 interrupt 作为参数的任何 json 可序列化负载。
# 当从工作流流式传输数据时，它将作为 Interrupt 出现在客户端。
"essay": essay, # 我们想要审核的论文。
# 我们可以添加任何需要的额外信息。
# 例如，引入一个名为 "action" 的键并提供一些指令。
"action": "Please approve/reject the essay",
})

return {
"essay": essay, # 生成的论文
"is_approved": is_approved, # 来自 HIL 的响应
}

更正：工作流可保持中断，等待外部审核；本例内存检查点仅在当前进程和实例存活期间有效，跨重启等待应改用持久化后端。

查看解释与参考资料

本例使用InMemorySaver，只在该进程与实例仍存活、检查点未丢失时可恢复。长期等待需持久化检查点后端及运维保留策略。

此工作流将撰写一篇关于“cat”主题的论文，然后暂停以获取人工审核。工作流可以无限期中断，直到提供审核为止。

当工作流恢复时，它会从头开始执行，但由于writeEssay任务的结果已经保存，任务结果将从检查点加载，而不是重新计算。

import time
import uuid
from langgraph.func import entrypoint, task
from langgraph.types import interrupt
from langgraph.checkpoint.memory import InMemorySaver

@task
def write_essay(topic: str) -> str:
"""撰写关于给定主题的论文。"""
time.sleep(1) # 这是长时间运行任务的占位符。
return f"An essay about topic: {topic}"

@entrypoint(checkpointer=InMemorySaver())
def workflow(topic: str) -> dict:
"""撰写论文并请求审核的简单工作流。"""
essay = write_essay("cat").result()
is_approved = interrupt(
{
# 提供给 interrupt 作为参数的任何 json 可序列化负载。
# 当从工作流流式传输数据时，它将作为 Interrupt 出现在客户端。
"essay": essay, # 我们想要审核的论文。
# 我们可以添加任何需要的额外信息。
# 例如，引入一个名为 "action" 的键并提供一些指令。
"action": "Please approve/reject the essay",
}
)
return {
"essay": essay, # 生成的论文
"is_approved": is_approved, # 来自 HIL 的响应
}

thread_id = str(uuid.uuid4())
config = {"configurable": {"thread_id": thread_id}}
for item in workflow.stream("cat", config):
print(item)

# >            },

# >        ),

论文已撰写完成，准备审核。一旦提供审核，我们就可以恢复工作流：

from langgraph.types import Command

# 从用户处获取审核（例如，通过 UI）
# 在这种情况下，我们使用布尔值，但这可以是任何 JSON 可序列化的值。
human_review = True

for item in workflow.stream(Command(resume=human_review), config):
print(item)

更正：{'workflow': {'essay': 'An essay about topic: cat', 'is_approved': True}}
