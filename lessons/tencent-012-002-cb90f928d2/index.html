MCP 支持两种通信方式：

STDIO 模式（本地进程）：

┌───────────────┐    stdin/stdout    ┌───────────────┐
│   MCP Client  │ ◄───────────────► │   MCP Server  │
│ (Agent)       │                    │ (weather.py)  │
└───────────────┘                    └───────────────┘

SSE 模式（远程服务）：

┌───────────────┐     HTTP/SSE       ┌───────────────┐
│   MCP Client  │ ◄───────────────► │   远程 MCP    │
│ (Agent)       │                    │   服务器       │
└───────────────┘                    └───────────────┘
