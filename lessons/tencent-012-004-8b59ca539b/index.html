第九章 Agent 工具调用

Agent 和普通聊天机器人的区别是：Agent 能使用工具。

定义工具

使用 @tool 装饰器：

更正：用受限算术语法解析器，限定数值、运算符、输入长度和计算量；不允许任意调用、名称和属性访问。search_web 返回占位字符串、get_weather 返回固定字典，也应在演示输出中明确标注。

calculator 会执行不可信表达式，捕获异常不能阻止已发生的文件、网络或进程副作用。

from langchain_core.tools import tool

@tool
def search_web(query: str) -> str:
 """搜索网络信息

    Args:
        query: 搜索关键词
    """
 # 实际实现
 return f"搜索 '{query}' 的结果：..."

@tool
def calculator(expression: str) -> str:
 """计算数学表达式

    Args:
        expression: 数学表达式，如 "2+2"
    """
 try:
        result = eval(expression)
 return f"计算结果: {expression} = {result}"
 except:
 return "计算错误"

@tool
def get_weather(city: str) -> str:
 """查询城市天气

    Args:
        city: 城市名称
    """
    weather_data = {
 "北京": "晴天，15-25度",
 "上海": "多云，18-28度",
 }
 return weather_data.get(city, f"{city}天气信息不可用")

工具定义要点

  1. 必须有 docstring：描述工具用途，AI 靠这个判断什么时候用
  1. 参数要有类型注解：让 AI 知道怎么传参
  1. Args 部分详细说明：每个参数是干什么的
