实例

from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

# 1. 定义模型 (Model)
llm = ChatOpenAI(
    model="deepseek-v4-pro",
    openai_api_key="你的_DEEPSEEK_API_KEY",
    openai_api_base="https://api.deepseek.com"
)

# 2. 定义提示词模板 (Prompt)
# system: 设定 AI 的角色
# user: 用户的具体输入
prompt = ChatPromptTemplate.from_messages([
 ("system", "你是一个资深的技术专家，擅长用通俗易懂的'大白话'解释复杂的科技概念。你的解释应该包含一个生动的比喻。"),
 ("user", "{concept}")
])

# 3. 定义输出解析器 (Output Parser)
# 将模型的 Message 对象直接转为纯字符串
parser = StrOutputParser()

# 4. 构建链 (Chain) - 使用管道符 | 连接
# 流程：输入字典 -> 填充 Prompt -> 发给 LLM -> 解析输出
chain = prompt | llm | parser

# 5. 调用链
concept_to_explain = "量子纠缠"
print(f"正在解释概念：{concept_to_explain} (流式输出)...\n")

# 这里的 chunk 是每次生成的片段
for chunk in chain.stream({"concept": "递归神经网络"}):
 print(chunk, end="", flush=True)

代码结构

Prompt

  • ChatPromptTemplate明确区分system / user
  • Prompt 是结构化输入函数，不是字符串

LLM

  • ChatOpenAI只是统一接口
  • LangChain 不增强模型能力，只增强可控性

OutputParser

  • 更正：本例 ChatOpenAI.invoke 返回 AIMessage，流式会产生消息块；经过 StrOutputParser 后，链的输出是字符串或字符串片段。

    查看解释与参考资料

    本课使用 Chat Model，但不能外推所有模型和调用方式；流式返回的是消息块，解析后是字符串。

    模型输出永远是Message
  • StrOutputParser是显式类型转换

  • 更正：需要纯文本时可用 StrOutputParser；也可按明确的数据契约直接处理消息对象或结构化输出。

    查看解释与参考资料

    工程可直接处理消息对象或使用模型结构化输出，Parser 并非所有应用的必需项。

    没有 Parser，工程不可控
