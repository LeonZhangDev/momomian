API Key 管理

AI Agent 开发需要访问各种 API 服务（如 OpenAI、Anthropic、DeepSeek 等），安全、有效地管理 API Key 至关重要。

1. 为什么需要安全管理 API Key？

  • 防止泄露：API Key 泄露可能导致经济损失
  • 访问控制：不同环境使用不同的 Key
  • 方便配置：团队协作时统一配置方式
  • 环境隔离：开发、测试、生产环境使用不同的 Key

2. 环境变量管理（推荐）

更正：开发环境可用不入库的 .env 保存配置，限制其访问并避免日志或前端输出；生产环境按部署条件使用受控环境变量或密钥管理服务。

查看解释与参考资料

.env 是配置约定，不提供加密或自动权限保护；还应控制文件访问、备份及部署时的数据流。

查看更正前的原段落

使用.env文件管理敏感信息，不提交到版本控制系统。

GOOGLE_API_KEY=你的Gemini密钥
SERPAPI_API_KEY=你的搜索API密钥

APP_ENV=development
LOG_LEVEL=INFO

# 数据库配置（如使用）
