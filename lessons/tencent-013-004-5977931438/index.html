安装方法

OpenClaw 的安装被设计得极为友好，即使是非开发者也能快速上手。

系统要求（不一定 Mac mini）：

  • 补充说明：内存取决于所用版本、并发、插件和是否本地运行模型。不能把2GB当作任意使用场景的充分条件；远程调用模型也不等于本地不消耗内存。

    硬件：极低，2GB RAM 即可运行。
  • 环境：支持 Mac, Windows, Linux，需要安装 Node.js (pnpm) 或使用 Docker。

1、推荐安装方式（一键脚本）：

直接通过终端，执行以下命令。

macOS/Linux 系统:

curl -fsSL https://openclaw.ai/install.sh | bash

Windows 系统：

补充说明：CMD片段中的install.cmd入口未在本次核验。当前官方给出PowerShell等安装方式；不要把不同Shell的语法混用，也不要仅凭下载命令无报错判断安装完成。

#PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex

#CMD
curl -fsSL https://openclaw.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

补充说明：运行环境要求已经变化，当前官方安装文档列出了比Node22更严格的版本范围。安装前应核对目标版本的要求，不能把“所有Node22及以上”当作长期保证。

查看解释与参考资料

OpenClaw：当前安装要求 ↗

这会自动安装 Node.js（≥22）并完成基本配置。

2、手动安装

补充说明：这是旧版要求。请以所安装版本的engine约束和官方安装文档为准；不要使用本课的旧数字判断当前环境一定兼容。

需要Node.js ≥22并完成基本配置：

使用 npm：

npm i -g openclaw

# 如果速度慢可以指定国内镜像
npm i -g openclaw --registry=https://registry.npmmirror.com

或使用 pnpm：

pnpm add -g openclaw

补充说明：下方的openclaw onboard启动向导，不能仅凭这条命令就声称后台服务已安装。是否安装服务取决于选项、平台与向导选择，完成后需查看gateway status。

安装完成后，初始化并安装后台服务（launchd / systemd 用户服务）：

openclaw onboard

3、从源码安装（开发模式）

git clone https://github.com/openclaw/openclaw.git
cd openclaw

pnpm install

pnpm ui:build   # 首次运行会自动安装 UI 相关依赖并构建前端界面
pnpm build      # 构建整个项目（包含后端与相关模块）

# 初始化 OpenClaw 并安装为系统后台服务（开机自动运行）
pnpm openclaw onboard --install-daemon

# 开发模式：监听 TypeScript 代码变更并自动重载网关服务
pnpm gateway:watch
