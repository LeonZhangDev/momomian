模型回退

当主模型失败时，自动回退到备用模型。模型回退适用于以下场景：

  • 构建能够处理模型中断的弹性代理。

  • 补充说明：备用模型单价较低，不代表这一轮总费用一定更低。主模型的失败尝试、底层重试及更长输入输出都可能产生费用；应按实际用量核对，并限制总尝试预算。

    通过回退到更便宜的模型来优化成本。
  • 跨 OpenAI、Anthropic 等提供商实现冗余。

API 参考：ModelFallbackMiddleware

from langchain.agents import create_agent
from langchain.agents.middleware import ModelFallbackMiddleware

agent = create_agent(
model="gpt-4o",
tools=[],
middleware=[
ModelFallbackMiddleware(
"gpt-4o-mini",
"claude-3-5-sonnet-20241022",
),
],
)

配置选项

first_modelstring | BaseChatModelrequired

当主模型失败时首先尝试的回退模型。可以是模型标识符字符串（例如 'openai:gpt-4o-mini'）或 BaseChatModel 实例。


*additional_modelsstring | BaseChatModel

如果之前的模型失败，按顺序尝试的额外回退模型
