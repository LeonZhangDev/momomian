从两句长短不同的文本走到批量向量

  • 按 B、L、H 标注输入与隐藏状态形状
  • 用 attention_mask 排除 padding
  • 算出带遮罩的均值池化并说明特殊词元策略

本单元的 2 篇材料共用这组串讲、小测和新卡。切换资料页不会产生重复的题目记录。

卡住时，先补哪一小节？
  • 张量与形状

先分词，再补齐同一批次的长度

本例使用人工词表编号，不调用真实 tokenizer。两条序列长度分别为 3、4，补齐后 input_ids 的形状为 [B,L]=[2,4]。编号只表示词表位置，不能直接把编号大小当成语义相似度。真实模型需要配套 tokenizer、特殊词元与最大长度约定。

attention_mask 描述哪些位置有效

第一条补了一个 0，mask 是 [1,1,1,0]；第二条没有填充，mask 是 [1,1,1,1]。这里 1 表示有效位置，0 表示 padding。具体接口如何接收遮罩要查模型约定，不能假设所有库的布尔遮罩语义完全相同。

池化要按有效位置计算分母

给定隐藏状态形状 [2,4,2]，先对每个位置乘 mask，再沿长度维求和，最后除以有效位置数。本例为演示计算，把有效特殊词元也算入均值；实际任务可以选择排除它们、使用 CLS 或采用模型推荐的池化方式。全为空的序列必须单独处理，不能除以 0。

把输入代进去，走一遍

以下是本站固定教学样例，用来观察规则，不是线上服务的测量结果。

人工 input_ids=[[101,7,102,0],[101,8,9,102]]；mask=[[1,1,1,0],[1,1,1,1]]。第一条隐藏状态 [[1,0],[3,2],[2,4],[9,9]]，第二条 [[0,2],[2,0],[2,4],[4,2]]。

步骤当前内容或状态为什么这样变化
确定批量形状input_ids=[2,4]；hidden=[2,4,2]2 条样本，每条补到 4 个位置，每个位置有 2 个特征。
遮掉第一条填充值第一条末项 [9,9]×0=[0,0]填充位置在本例恰好非零，更能看出直接平均的影响。
第一条有效求和[1,0]+[3,2]+[2,4]=[6,6]；有效数 3按有效位置数作分母，得到 [2,2]。
第二条均值[0,2]+[2,0]+[2,4]+[4,2]=[8,8]；除以 4 得 [2,2]第二条所有位置有效，分母为 4。
错误对照第一条不遮罩时 ([6,6]+[9,9])/4=[3.75,3.75]错误混入 padding，表示会随填充数量改变。

最后得到：最终池化结果为 [[2,2],[2,2]]，形状 [B,H]=[2,2]。这只验证给定隐藏状态的池化公式，不说明两句话在真实模型中语义相同。

查看完整 Python 推导与预期输出

标准库教学程序。固定输入的输出会随课程构建核对；不访问模型或外部服务。

hidden = [[[1,0],[3,2],[2,4],[9,9]], [[0,2],[2,0],[2,4],[4,2]]]
masks = [[1,1,1,0], [1,1,1,1]]
pooled = []
for sequence, mask in zip(hidden, masks):
    count = sum(mask)
    assert count > 0
    pooled.append([sum(row[j]*m for row,m in zip(sequence,mask))/count for j in range(2)])
print(pooled)
print([sum(row[j] for row in hidden[0])/4 for j in range(2)])

预期输出：

[[2.0, 2.0], [2.0, 2.0]]
[3.75, 3.75]

如果这一步出错呢？

触发条件：把 input_ids 当成向量直接求平均，或把所有 L 个位置都计入分母。

词元编号平均与隐藏特征池化不是同一运算；本例第一条错误均值得到 [3.75,3.75]，与有效位置结果 [2,2] 不同。

恢复方法：同时展示 input_ids、mask、hidden 的形状；把一条样本补得更长，检查同样有效内容的池化是否保持约定结果。

查看解释与参考资料

with、return 与函数体其余行缩进不一致，会触发缩进错误。

from transformers import AutoModel, AutoTokenizer
import torch

model = AutoModel.from_pretrained("bert-base-uncased")
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

def get_sentence_embedding(text: str) -> torch.Tensor:
    inputs = tokenizer(text, return_tensors="pt", max_length=512, truncation=True)
 with torch.no_grad():
        outputs = model(**inputs)
 # 对所有 token 做均值池化（Mean Pooling）
    token_embeddings = outputs.last_hidden_state          # [1, seq_len, 768]
    attention_mask = inputs["attention_mask"].unsqueeze(-1)
    mean_embedding = (token_embeddings * attention_mask).sum(1) / attention_mask.sum(1)
 return mean_embedding  # [1, 768]

vec = get_sentence_embedding("Hello world")
print(vec.shape) # -> torch.Size([1, 768])
