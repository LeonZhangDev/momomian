推荐学习路径

第一阶段：理解基础（1 周）

  1. 理解 LLM API 调用，能用 OpenAI SDK 发起请求
  1. 跑通本文 LangChain 顺序链示例
  1. 理解 Prompt Engineering 基本原则

第二阶段：工具与 Agent（2 周）

  1. 学会用 @tool 装饰器定义工具
  1. 跑通 ReAct Agent 示例，观察 verbose 日志理解循环逻辑
  1. 用 Dify 或 n8n 搭建一个可视化 Workflow 原型

第三阶段：复杂 Workflow（3 周）

  1. 学习 LangGraph 状态图，实现带条件分支的工作流
  1. 用 CrewAI 实现一个双 Agent 协作任务
  1. 接入真实工具（Tavily 搜索、Python REPL）
  1. 用 LangSmith 观测并调试你的 Workflow

第四阶段：生产就绪（持续）

  1. 实现错误重试、结构化输出解析
  1. 成本监控与优化（模型分级使用）
  1. 部署到生产，设置监控告警

    从全文匹配本站通用术语表，并摘录少量原文定义。未列出的专有词需继续查证。

    Agent
    围绕目标读取状态、选择动作、观察结果并判断是否继续的程序。行动权限与停止条件需要明确设计。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LLM
    通过训练学习语言规律、根据上下文生成内容的模型；输出可用性和事实正确性仍需要检查。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Prompt
    向模型提供任务、上下文、约束和输出要求的输入内容；提示本身不能代替程序权限校验。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    重试
    操作失败或结果未知后再次尝试。需要区分错误类型、限制次数，并先判断外部副作用是否已发生。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LangChain
    模型、消息、工具等应用组件的框架生态。具体接口以课程标注版本和官方文档为准。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LangGraph
    使用图与持久状态组织工作流的框架。图的结构不自动保证任务正确、终止或外部操作安全。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    API
    程序之间约定的调用入口，包括输入、返回和错误处理。是否可用依赖具体实现、权限和环境。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    SDK
    帮助调用某种平台能力的一组开发工具或库。SDK 版本与服务端 API 版本需要区分。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    函数
    接收约定参数并执行一段逻辑的代码单元。需要明确返回值、异常与副作用。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    日志与追踪
    记录一次处理的输入、状态、工具结果或耗时，帮助定位错误；记录时应控制敏感信息。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    ReAct
    把决策与动作、外部观察交替组织的一类 Agent 模式。外部轨迹与模型内部思考并不等同。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    状态图
    用节点、边和状态表达流程。需分别检查状态更新、路径条件、恢复和终止。本站通用释义；具体接口以适用版本为准。 回看本课上下文
