一个流里不一定每条都有文字

以 Chat Completions 文本流为例，事件可能只声明角色，可能携带 content 增量，也可能报告结束原因；启用且支持用量返回时，还可能出现没有 choices 的用量事件。先判断事件内容，再读取字段。空增量不应显示成 None，更不能让页面崩溃。

界面需要记录生命周期

可以把页面状态分为等待、接收中、完成、中断和已取消。收到第一段文本时显示接收中；收到符合接口约定的结束信号并完成必要校验后再显示完成。网络断开时保留已显示的草稿，同时标明不完整。流式提高可感知的响应速度，不会自动提高答案正确性。

工具参数片段和文本片段分别处理

文本可逐段显示，工具参数则需要按调用标识分组、收齐后解析与验证，不能看到半个 JSON 就执行。页面取消等待也不证明远端写操作撤销；涉及外部动作时仍应按原请求编号核对结果。

以下是本站固定教学样例，用来观察规则，不是线上服务的测量结果。

固定教学事件依次为：role=assistant；content="你"；content="好"；finish_reason="stop"；usage.total_tokens=9 且 choices=[]。没有真实请求。

步骤当前内容或状态为什么这样变化
1 · 角色事件text=""；status=等待没有文字，保持缓冲区为空。
2 · 第一段text="你"；status=接收中追加非空 content，记录首次文字出现。
3 · 第二段text="你好"；status=接收中增量按到达顺序追加，不用后一片覆盖前一片。
4 · 结束finish_reason=stop；status=完成这是本例预期的文本结束。若为 length，应说明达到输出上限，不能当作完整满足任务。
5 · 用量text 仍为“你好”；total_tokens=9用量属于统计，不追加成文字；choices=[] 也可以是合法的用量事件形状。

最后得到：最终文字为“你好”，状态为完成，用量记录为 9。若第二片后断流而没有结束依据，应保留“你好”但标为中断，不能由文字看起来完整推断流程已完成。

查看完整 Python 推导与预期输出

标准库教学程序。固定输入的输出会随课程构建核对；不访问模型或外部服务。

events = [{"role": "assistant"}, {"text": "你"}, {"text": "好"}, {"finish": "stop"}, {"usage": 9}]
text, finished, usage = "", False, None
for event in events:
    text += event.get("text", "")
    if "finish" in event:
        finished = event["finish"] == "stop"
    if "usage" in event:
        usage = event["usage"]
print(text, "完成" if finished else "不完整", usage)

预期输出：

你好 完成 9

如果这一步出错呢？

触发条件：每条事件都直接读取 choices[0].delta.content，或连接断开后无条件显示“完成”。

角色事件无 content；用量事件 choices=[]；断流走出循环后被误标成功。三种情况可能分别造成 None 拼接、越界和不完整结果冒充完成。

恢复方法：按事件类型检查存在性；结束原因独立记录。出错保留草稿并提示重试或查原任务。取消后显示“已停止等待，远端状态需核对”，有副作用时不直接新建请求。

from openai import OpenAI

def get_response():
    client = OpenAI(
        api_key="sk-xxx",
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
 )

    completion = client.chat.completions.create(
        model="qwen-plus",
        messages=[
 {'role': 'system', 'content': 'You are a helpful assistant.'},
 {'role': 'user', 'content': '你是谁？'}
 ],
        stream=True,
        stream_options={"include_usage": True}
 )

 for chunk in completion:
 # chunk 里可能没有 choices 或 delta
 if hasattr(chunk, "choices") and len(chunk.choices) > 0:
            choice = chunk.choices[0]
 if hasattr(choice, "delta") and hasattr(choice.delta, "content"):
 print(choice.delta.content, end='', flush=True)

if __name__ == '__main__':
    get_response()
