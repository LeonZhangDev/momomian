知识点讲解

讲一下 Agent 中的"长短期记忆"

Agent 的记忆系统借鉴了认知科学中人类记忆的分层模型：

短期记忆（Short-term Memory / Working Memory）：

  • 载体：LLM 的上下文窗口

  • 更正：容量受所用模型和接口的上下文限制，具体输入及输出上限需查对应版本。

    查看解释与参考资料

    模型窗口并非统一落在这个范围。

    容量：受模型上下文窗口限制（200K-1M tokens）
  • 持续时间：单次会话内有效
  • 内容：当前对话历史、工具调用结果、中间推理步骤

  • 更正：特点：进入上下文即可被本轮使用，但质量取决于内容与模型；容量有限，能否跨会话恢复取决于应用是否保存并重新加载状态。

    查看解释与参考资料

    上下文可用不代表高精度；会话状态可以由应用保存并在下次恢复，不一定结束即丢失。

    特点：高精度、即时可用、容量有限、会话结束即丢失
  • 类比：人类的工作记忆，如同你在解题时脑海中暂存的信息

长期记忆（Long-term Memory）：

  • 载体：向量数据库、关系数据库、文件系统

  • 更正：容量：相对模型窗口更易扩展，但受存储、检索性能、成本和数据维护约束。

    查看解释与参考资料

    外部存储仍受容量、费用、索引和维护约束。

    容量：理论上无限
  • 持续时间：跨会话持久化
  • 内容：用户画像、历史交互摘要、重要决策、知识沉淀
  • 特点：需要检索才能使用、可能存在信息损失、需要定期维护更新
  • 类比：人类的长期记忆，需要"回忆"才能激活

两者的协作机制：

  1. 会话开始时，从长期记忆中检索与当前任务相关的信息，注入到短期记忆（上下文窗口）
  1. 会话进行中，短期记忆不断更新
  1. 会话结束或达到阈值时，从短期记忆中提取重要信息写入长期记忆
  1. 形成闭环：长期记忆 → 检索 → 注入短期 → 推理交互 → 提取 → 更新长期记忆
