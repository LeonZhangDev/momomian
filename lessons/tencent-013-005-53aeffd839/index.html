OpenClaw 快速上手

使用以下命令一键安装。

macOS/Linux：

curl -fsSL https://openclaw.ai/install.sh | bash

Windows（PowerShell）：

iwr -useb https://openclaw.ai/install.ps1 | iex

启动引导

安装完成后，运行 Onboarding 完成初始配置。这是最关键的一步：

openclaw onboard --install-daemon

新手引导会配置认证、Gateway 网关设置和可选渠道。：

  • 鉴权配置：设置 Gateway Token 或 Password，保护你的 API 接口
  • 模型提供商配置：选择并配置你的 LLM（如 Anthropic API Key）
  • 渠道配置（可选）：连接 Telegram Bot、WhatsApp 等聊天渠道
  • 安装系统服务：--install-daemon参数让 Gateway 开机自启

补充说明：--force不是排查端口冲突的默认做法，可能影响已有监听进程。应先确认占用者，选择空闲端口或在明确归属后处理原进程。

Control UI 的主要功能：

  • 聊天界面：不需要配置任何渠道，直接在浏览器里和 AI 对话
  • 状态监控：查看 Gateway 健康状态、渠道连接情况
  • 会话管理：查看和管理不同渠道的对话历史

Gateway 热重载机制

补充说明：此表是本课所用版本的配置模型，不能推断当前发布版的默认值或所有配置都可即时生效。修改前查对应版本schema与重载说明，观察是否发生重启。

OpenClaw 支持配置热重载，默认为hybrid模式：

gateway.reload.mode

行为说明

off

不自动重载，需手动重启

hot

仅应用安全变更（不中断连接）

restart

任何变更都重启 Gateway

hybrid（默认）

能热应用的热应用，需要重启的自动重启
