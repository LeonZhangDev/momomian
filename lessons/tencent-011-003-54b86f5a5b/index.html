先决定值不值得记，再决定写到哪里

一句话进入本次上下文不等于长期保存。可以先抽取候选，再按产品约定判断是否是稳定偏好、是否有明确来源、是否允许保存。本文教学规则要求用户明确确认，才写入饮品偏好；这是本例的产品规则，不是所有框架自动提供的功能。

同一事实用稳定键更新，不不断追加矛盾记录

为虚构用户u1保存 fact_key=drink，版本v1为咖啡。用户更正为茶后，应产生v2并让旧版本失效；检索时过滤有效版本。向量相似度只能找到相近记录，不能自行决定哪个版本是用户最终决定。还要保留来源、时间、范围与更正关系。

用户隔离、线程范围和磁盘持久化分开

线程历史只属于该次会话；长期事实可以按用户命名空间跨线程读取。命名空间本身不是授权检查：服务端仍要确认请求者有权访问u1。内存字典或InMemoryStore在进程退出后通常不保留数据；跨进程恢复需要真实持久后端与保存规则。删除还要让索引、缓存及后续注入失效，并按实际保留政策处理历史副本。

1 · 候选candidate={user:u1,key:drink,value:咖啡}；未入库当前看见这句话不等于获得保存许可。
2 · 确认写入(u1,drink,v1)=咖啡，active=true记录确认与来源，不按裸文本作为全局公共事实。

4 · 跨线程读取u1/thread-b→茶；u2→无此事实读取范围按已授权用户限制，线程变化不自动获得别人记忆。
5 · 删除drink不再参与检索与上下文注入同时处理主存、索引与缓存；若有依法或按约定保留的历史副本，应如实说明范围。

最后得到：u1更正后使用茶，u2不能读到u1的事实。删除后不再把该偏好提供给模型。下方标准库代码只演示内存键值更新与隔离，不证明磁盘持久化、权限系统或完整删除已实现。

记忆系统设计

人类的记忆分为短期记忆和长期记忆，AI Agent 的记忆系统也采用了类似的设计。

理解这两种记忆的区别和用途，是构建智能 Agent 的基础。

短期记忆：Agent 的工作记忆

短期记忆就像是 Agent 的工作台，存储当前对话的上下文和临时信息。

特点：

  • 容量有限：通常只能保存最近的几次对话（如最近的 10-20 轮对话）
  • 快速访问：读取和写入速度很快
  • 临时性：对话结束后通常会被清除或压缩
  • 上下文相关：直接影响当前的响应生成

主要用途：

  • 保持对话的连贯性
  • 存储当前任务的中间结果
  • 记住用户在当前对话中提到的偏好

class ShortTermMemory:
    """短期记忆实现"""
    def __init__(self, max_turns=10):
        self.max_turns = max_turns
        self.conversation_history = []
        self.temporary_data = {}
    def add_message(self, role, content):
        message = {"role": role, "content": content, "timestamp": time.time()}
        self.conversation_history.append(message)
        if len(self.conversation_history) > self.max_turns:
            self.conversation_history.pop(0)
    def get_context(self):
        """获取对话上下文（用于发送给LLM）"""
        return self.conversation_history[-self.max_turns:]
    def store_temp(self, key, value):
        self.temporary_data[key] = value
    def get_temp(self, key, default=None):
        return self.temporary_data.get(key, default)
    def clear_temp(self):
        self.temporary_data.clear()

长期记忆：Agent 的知识库

长期记忆就像是 Agent 的档案室，存储重要的、需要长期保留的信息。

特点：

  • 容量大：可以存储大量信息
  • 持久化：信息会长期保存，不会自动清除
  • 检索式访问：通过查询检索相关信息，而非顺序读取
  • 结构化存储：信息通常以结构化方式存储，便于检索

主要用途：

  • 存储用户的个人信息和偏好
  • 积累知识和经验
  • 记住重要的对话内容
  • 保存任务执行结果
