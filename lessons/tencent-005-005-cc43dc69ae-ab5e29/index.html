4. 记忆模块 —— Agent 的"工作笔记"

如果没有记忆，Agent 每次回复都是"失忆"状态——忘了你之前说过什么，忘了它自己做过什么。记忆模块解决了这个问题，它分两类：

  • 短期记忆 / 对话历史：记录本次对话中说过的话，让 Agent 在多轮对话中保持连贯。就像你和朋友聊天，你不需要每句话都重新解释背景。
  • 长期记忆 / 知识库：通过向量数据库等技术存储的专属知识（例如公司内部文档、用户偏好），用于增强模型的能力。初学者可暂时忽略这部分，先掌握短期记忆即可。
