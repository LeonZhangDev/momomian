2. 决策模块（大脑）—— Agent 的"指挥官"

这是 Agent 的核心，通常由一个AI 模型（如大语言模型 LLM）驱动。它拿到感知模块传来的信息，负责做三件事：

  • 理解：这条信息是什么意思？用户想要什么？
  • 推理：当前情况下，我该怎么做？
  • 规划：下一步（或接下来几步）应该调用哪个工具、做什么操作？
