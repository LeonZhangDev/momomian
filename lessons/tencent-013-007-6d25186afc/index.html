安装环境说明

QoderWake 支持本地部署和云端部署。

建议部署在稳定在线、网络良好的常开设备或云桌面环境中，以保障数字员工 7x24 小时持续运行。

更正：当前官方资料已提供Windows安装入口；安装前按系统和芯片选择对应版本。

QoderWake：发布说明 ↗

Windows 版本敬请期待，暂未对外开放，请先在 macOS 或 Linux 上使用。

本地部署要求

推荐部署在可长期稳定运行的本地设备上，例如 Mac mini，以获得更好的 7x24 小时运行体验。

补充说明：这是原安装和浏览器登录路径的说明，不是Web Console服务器本身必须带GUI。远程或无桌面环境应按当前官方部署文档安排授权及访问方式，不要仅凭此表购买云桌面。

  • 已完成仓库认证配置
