知识点讲解

LangSmith概述

LangSmith 提供用于开发、调试和部署 LLM 应用程序的工具。 它帮助您在一个地方追踪请求、评估输出、测试提示词并管理部署。 LangSmith 是框架无关的，因此您可以将其与 LangChain 的开源库 langchain 和 langgraph 一起使用，也可以单独使用。 先在本地进行原型设计，然后借助集成的监控和评估功能转向生产环境，以构建更可靠的 AI 系统。

LangGraph Platform 现已更名为 LangSmith Deployment。

开始使用

创建账户

在smith.langchain.com注册（无需信用卡）。 您可以使用Google、GitHub或邮箱登录。

创建 API 密钥

前往您的 设置页面 → API Keys → Create API Key。 复制密钥并安全保存。
