先写清这个问题需要哪些证据

问题是“2026标准版退款期限及已使用服务的例外是什么”。教学标准相关集合为{d2,d4}。六个文档：d1=2025标准版14天，d2=2026标准版7天，d3=2026专业版30天，d4=2026标准版已使用服务例外，d5=无规则的营销介绍，d6=发票抬头说明。所有文字与排名为固定教学数据。

融合比较名次，重排比较候选与问题

本例BM25排名[d1,d2,d3,d4]，向量排名[d3,d4,d2,d5]。RRF用k=1便于手算，每路同一ID只算一次，分数为各路1/(1+rank)之和。真实应用常需要另选k并评估，不能把教学值当通用推荐。融合后的Top2仍可能排错；重排只能调整拿到的候选，找不回根本没进入候选池的证据。

改善多少，要和成本一起比较

以相同Top2和相关集合比较：向量Top2命中1/2，融合Top2仍命中1/2；从融合Top4重排后Top2命中2/2。重排分数为本页给定值，不是真实模型能力测量。假定向量4ms、融合加1ms、重排再加6ms，则总耗时4、5、11ms；这只练习计算与取舍，不能推出生产性能。

把输入代进去，走一遍

以下是本站固定教学样例，用来观察规则，不是线上服务的测量结果。

固定排名：BM25=[d1,d2,d3,d4]；vector=[d3,d4,d2,d5]；相关集合={d2,d4}。融合k=1。同分按ID升序。重排给分d2=.94、d4=.86、d3=.40、d1=.20、d5=.10。

步骤当前内容或状态为什么这样变化
1 · 只看向量Top2[d3,d4]；命中d4；precision=recall=1/2d3年份对但版型错。相关集合有2项，返回也2项，所以这一次两指标数值相同。
2 · 计算融合d3=1/4+1/2=.75；d2=1/3+1/4=7/12≈.5833每路名次从1起；不同来源的原始分数不直接相加。
3 · 继续核算d4=1/5+1/3≈.5333；d1=.5；d5=.2融合顺序为[d3,d2,d4,d1,d5]，Top2仍只命中1项。
4 · 重排候选融合Top4=[d3,d2,d4,d1] → [d2,d4,d3,d1]使用给定的重排分数，Top2现在同时包含期限和例外。d6没召回，也没有被重排凭空造出。
5 · 质量与代价Top2命中1→1→2；假设耗时4→5→11ms在相同样本和返回数下比较。仅这个问题的改善不能代表总体提升。

最后得到：最终候选d2与d4分别支持期限和例外。这个例子说明：融合不保证第一名正确；重排若要发挥作用，相关证据必须进入其候选池。还需检查版本、版型和权限。

标准库教学程序。固定输入的输出会随课程构建核对；不访问模型或外部服务。

from fractions import Fraction

rankings = [["d1", "d2", "d3", "d4"], ["d3", "d4", "d2", "d5"]]
scores = {}
for ranking in rankings:
    seen = set()
    for rank, doc in enumerate(ranking, 1):
        if doc not in seen:
            scores[doc] = scores.get(doc, Fraction(0)) + Fraction(1, 1 + rank)
            seen.add(doc)
for doc in sorted(scores, key=lambda item: (-scores[item], item)):
    print(doc, format(float(scores[doc]), ".4f"))

预期输出：

d3 0.7500
d2 0.5833
d4 0.5333
d1 0.5000
d5 0.2000

如果这一步出错呢？

触发条件：把提高TopK当成唯一优化，或让重排只看到错误的Top1。

只传融合Top1=d3给重排 → d2和d4都不在输入 → 再好的排序也无法选中它们；仅看答案流畅会把专业版30天错套标准版。

恢复方法：先判断相关块是否进入候选池：没进则查查询、切分、过滤和召回；已进但靠后再查融合与重排。记录相同样本下的质量、成本和耗时，避免只选成功例。

3. Retrieval（检索：快速找到相关知识）

索引建好后，用户来提问了。检索阶段的任务是：从海量知识中快速找出最相关的那几条。


3.1 查询处理

用户输入的问题往往不是完美的搜索词。比如：

用户原始问题："我吃了阿司匹林后胃疼怎么办？"

需要优化为：
"阿司匹林 胃痛 副作用"（关键词提取）
"阿司匹林导致的胃部不适如何处理"（问题改写）

3.3 检索策略

检索系统通常采用混合搜索方法，结合向量搜索（找语义相似的文档）和关键词搜索（精确匹配），然后对结果进行排序和过滤。

  1. 单纯向量搜索
  • 优点：能理解语义
  • 缺点：对专有名词、数字等不敏感
  1. 混合搜索（Hybrid Search）
  • 向量搜索 + 关键词搜索
  • 综合排序，取最优结果

更正：明确去重ID、融合方法及缺失候选的处理；可比较归一化加权或基于名次的RRF，并在固定相关标注上验证。

查看解释与参考资料

融合函数未定义，且两路原始分数通常不在同一量纲，alpha本身不能解决可比性。

#混合搜索示例
def hybrid_search(query, alpha=0.5):
 # alpha: 向量搜索权重（0-1）
 # 向量搜索结果
    vector_results = vectorstore.similarity_search(query, k=10)
 # 关键词搜索结果（BM25算法）
    keyword_results = bm25_search(query, k=10)
 # 融合排序
    final_results = merge_results(vector_results, keyword_results, alpha)
 return final_results[:3] # 返回top3
  1. 重排序（Re-ranking）

初步检索后，用更精细的模型重新排序，提高精度。

from sentence_transformers import CrossEncoder

#加载重排序模型
reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

#对检索结果重新打分
query = "阿司匹林副作用"
candidate_docs = ["文档1内容", "文档2内容", "文档3内容"]

scores = reranker.predict([(query, doc) for doc in candidate_docs])

#按分数排序
ranked_docs = [doc for _, doc in sorted(zip(scores, candidate_docs), reverse=True)]
