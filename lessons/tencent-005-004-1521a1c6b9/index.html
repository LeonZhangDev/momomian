    Agent
    围绕目标读取状态、选择动作、观察结果并判断是否继续的程序。行动权限与停止条件需要明确设计。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    LLM
    通过训练学习语言规律、根据上下文生成内容的模型；输出可用性和事实正确性仍需要检查。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Token
    分词器处理文本得到的单位。它不固定等于一个汉字、一个单词或一个字符。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    上下文窗口
    单次模型处理所能容纳的信息范围。放进窗口的信息与存到外部数据库的信息不同。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    RAG
    先从资料中取回相关内容，再将检索结果作为生成回答的上下文；检索与回答依据应分别检查。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Embedding
    将文本等对象表示为数值向量的方法，用于比较或检索；向量相近不自动证明事实正确。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Top-k
    按指定分数或顺序取前 k 个候选。候选数量、排序质量与回答可信度是不同问题。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    缓存
    保存可复用结果以减少重复工作。命中率、键的范围、失效与更新策略会影响正确性。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    Transformer
    利用注意力等结构处理序列表示的一类模型架构。具体结构、输入与训练目标随模型而异。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    注意力
    根据输入表示计算并汇总相关信息的机制。权重不是对模型所有行为的完整因果解释。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    GPT
    常用于生成任务的一类自回归语言模型家族；具体上下文、能力和接口取决于所用模型。本站通用释义；具体接口以适用版本为准。 回看本课上下文
    微调
    在已有模型基础上继续训练，使其适应特定任务或数据。训练收益应通过独立评测判断。本站通用释义；具体接口以适用版本为准。 回看本课上下文
